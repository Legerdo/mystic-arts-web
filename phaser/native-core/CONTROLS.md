# 조작 안내 근거 — 2026-10-18

인터넷의 [DiscStation 기술표](https://w.atwiki.jp/discstation/pages/50.html)와 [한국어 리뷰의 조작 설명](https://runingmongmong.tistory.com/130)을 원본 입력표(0x4DA5C8), 커맨드 판정(0x465129), 플레이어 갱신(0x45FB72)에 대조했다. 인터넷 자료는 팬 작성 자료이며 공식 매뉴얼로 표기하지 않는다.

웹에 남긴 항목: 이동/대시, 점프/발판 통과/공중 급강하, 가드/하단 공격, 지상·공중 콤보, 3타 후 위/아래 후속타, 대시 공격, 위 두 번 공격, 아래→앞 공격, 아래 두 번 공격(지상/공중), 앞→뒤→앞 공격.

커맨드 번호 3/4/5/6/7은 각각 앞-뒤-앞 / 아래-앞 / 앞-중립-앞 / 아래-중립-아래 / 위-중립-위 패턴이다. `positive-commands-final-01.json`의 원본 CPU 판정과 대조했다. 실제 기술 발동은 원본 플레이어 코드의 지상/공중, 회복, 명중, 기력 조건을 따른다. 모든 기술을 이번에 실플레이로 각각 확인했다는 뜻은 아니다.

아래→위 공격 및 뒤→앞 콤보 분기는 코드에 존재하더라도 확인한 인터넷 표와 교차 확인되지 않아 화면 설명에서 제외했다. 동시 아래+앞 공격의 슬라이딩 설명은 확인한 원본 분기와 일치가 확정되지 않아 제외했다. 자료마다 서로 다르게 부르는 기력 기술 이름은 임의로 확정하지 않고 기능과 입력으로 안내했다.

조작 안내는 선택 탭 없이 게임 양옆(좁은 세로 화면은 아래)에 표시한다. 화면 높이가 부족하면 안내 패널의 이전/다음 버튼을 사용한다. 화면 확대와 전체화면에서는 안내를 숨긴다. 원본 키 판정과 게임 규칙은 바꾸지 않았다.

가독성 정리: 동작 이름, 입력 키캡, 발동 조건을 분리했다. `후`는 앞 입력 뒤에 다음 입력을 이어서 하라는 뜻이며, `+`로 묶인 키는 동시에 누른다. 같은 방향을 연속 입력할 때 중간에 키를 떼라는 안내를 유지한다. 이동·방어·콤보·메뉴를 묶고, 특수기의 기력 조건을 강조했다. 논쟁적인 기술 이름이나 새로운 기술은 추가하지 않았다.
